code-health

A Claude Code plugin that finds where code is expensive to change, guides an agent through fixing it, and measures whether later changes got cheaper. It works from git history and source structure, runs locally, and sends nothing anywhere.

It is a suite of four tools, each a command line program with skills that tell Claude when to run it:

cochange
Where change effort concentrates, and which files change together.
complexity
Which functions are hard to understand, and where the complexity comes from.
structure
Which dependencies make change expensive.
locality
Which code lives far from the code that uses it.

Install it in Claude Code:

/plugin marketplace add dave-hillier-co/code-health
/plugin install code-health@code-health
